## Overview
The **City Issue Reporting System (CIRS)** is a web-based application developed by **Shubham Ramesh Rathod** to help citizens report city-related issues efficiently.  

The system allows users to:  
- Submit complaints about city infrastructure, water, electricity, sanitation, and other public services.  
- Track the status of their complaints in real-time.  
- Provide feedback on resolved issues.  

Admins and city officials can:  
- View and manage complaints submitted by citizens.  
- Assign complaints to relevant departments.  
- Monitor progress and ensure timely resolution.  

**Objective:** Developed by **Shubham Ramesh Rathod**, this project bridges the gap between citizens and authorities for faster and more transparent issue resolution.

---

## Features
- **User Features:**
  - User registration and secure login
  - Submit complaints with description and optional images
  - Track complaint status (Pending, In Progress, Resolved)
  - Provide feedback after resolution
  - View complaint history

- **Admin Features:**
  - Admin login and dashboard access
  - View all submitted complaints
  - Filter complaints by category or department
  - Assign complaints to departments
  - Update complaint status
  - Generate reports for resolved and pending complaints

- **General Features:**
  - Responsive, user-friendly interface
  - Categorized complaints for easy management
  - Data security and authentication
  - Real-time status updates
